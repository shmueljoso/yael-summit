# Yael Summit · Constellation

אתר הכנס הבינלאומי של קרן יעל למנהלי בתי ספר יהודיים בתפוצות. נושא הכנס: **Constellation**. כל מנהל הוא כוכב, וחיבורים קטנים ביניהם יוצרים קבוצת כוכבים.

במרכז האתר: **חיבורים בין מנהלים**. נרשמים בשם מלא, יוצרים פרופיל, מקבלים הצעות למי כדאי להכיר, מתחברים, ואחרי החיבור רואים פרטי קשר ומדברים בהודעות.

## מפת האתר
| עמוד | כתובת | מי רואה |
|---|---|---|
| דף פתיחה + הרשמה/כניסה | `#/join`, `#/signin` | כולם |
| The Summit (פרטי הכנס, כרגע Coming soon) | `#/summit` | כולם |
| Constellation: בקשות, הצעות לחיבור, החיבורים שלי | `#/` | רשומים |
| People: רשימה, חיפוש ומפת כוכבים | `#/people`, `#/map` | רשומים |
| פרופיל בסגנון רשת חברתית | `#/u/<id>` | רשומים |
| עריכת פרופיל, תמונה, קישורים | `#/me/edit` | הבעלים |
| הודעות | `#/messages`, `#/messages/<id>` | רק בין מחוברים |
| הלוח: שאלות, רעיונות, הצעות עזרה (מתורגם לאנגלית) | `#/board` | רשומים |

**פרטיות:** כל רשום רואה שם, תמונה, תפקיד, בית ספר, מיקום, ביו ונושאים. מייל, טלפון וקישורים לרשתות, וגם הודעות, נפתחים רק אחרי חיבור מאושר.

## מבנה הקוד
```
public/              האתר (HTML/CSS/JS, בלי שלב בנייה)
  app.js             כל המסכים
  styles.css         העיצוב (צבעי הסמל: נייבי, כחול מלכותי, זהב)
  assets/            סמל הכנס
src/worker.js        ה-Worker: מגיש את public/ ומפנה את /api/* לקוד
src/api/             auth · profile · connections · messages · board
src/lib/             db (D1 + סיסמאות + סשנים) · http · gemini
wrangler.jsonc       הגדרות Cloudflare
```

## Cloudflare
ה-Worker `yael-summit` מחובר לגיטהאב ובונה את `main` עם `npx wrangler deploy`.

| מה | איפה | הערה |
|---|---|---|
| `DB` (D1) | `wrangler.jsonc` | משתמשים, חיבורים, הודעות, פוסטים. מסד `yael-summit`, המזהה קבוע בקובץ. הטבלאות נוצרות לבד בשימוש הראשון. |
| `BOARD` (KV) | `wrangler.jsonc` | תמונות פרופיל, מטמון AI, הגבלות קצב |
| `GEMINI_API_KEY` | Settings → Variables and Secrets (Secret) | תרגום בלוח ו"Why meet?" |
| `SIGNUP_CODE` | Settings → Variables and Secrets (Secret), **לא חובה** | אם מוגדר, צריך את הקוד כדי להירשם. לשים אותו בהזמנה למנהלים. |

## חיסכון בקרדיטים של Gemini
- ההתאמה בין מנהלים היא חישוב רגיל, בלי AI.
- "Why meet?" רץ רק בלחיצה, ונשמר ל-60 יום לכל זוג פרופילים.
- פוסט בלוח מתורגם פעם אחת, בזמן הפרסום. פוסט באנגלית לא עובר דרך AI.
- פלט JSON קצר, thinking מינימלי, והגבלת קצב לכל משתמש.

## פיתוח מקומי

```
npx wrangler dev --local
```
